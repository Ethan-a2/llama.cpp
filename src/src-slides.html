核心模型层

llama-model.cpp / .h

  • struct llama_model 主模型结构体，前向传播入口
  • llama_model_load / llama_model_free 模型生命周期管理
  • llama_model_apply_lora LoRA 适配器应用
  • llama_decode / llama_batch 核心推理调用
  • llama_tokenize 文本转 token

llama-arch.cpp / .h

  • llama_architecture 模型架构定义枚举
  • llama_n_embd / llama_n_layer 从 arch 获取维度参数
  • llm_graph_builder 计算图构建器
  • 模型层类型定义 LLM_TOKEN_EMBD, LLM_ATTN, LLM_FFN...
model 是整个系统的核心抽象
包含 vocab, hparams, memory 等所有子模块
所有计算通过 llama_decode 驱动
📦
模型加载 & 保存

llama-model-loader.cpp/h

  • llama_model_loader 加载器上下文，引用计数管理
  • llama_load_model_file 从 GGUF 文件加载完整模型
  • llama_read_missing_tensor 延迟加载缺失的 tensor
  • mmap / munmap 集成 内存映射支持大模型
  • 迁移路径 旧格式 (llama_file_load) → GGUF

llama-model-saver.cpp/h

  • llama_model_saver 序列化写入器
  • llama_save_model_file 导出为 GGUF 格式
  • write_meta / write_tensors 元数据 + 权重写入
GGUF = GGML Unified Format
支持 mmap 零拷贝加载
元数据与权重分离存储

参数系统

llama-hparams.h (超参数)

  • n_vocab 词表大小
  • n_embd embedding 维度
  • n_head / n_head_kv attention head 数
  • n_layer Transformer 层数
  • n_ff / n_rot FFN 维度和 rope 维度
  • ftype / qntver 量化类型和版本

llama-cparams.h (计算参数)

  • n_ctx 上下文窗口大小
  • n_gpu_layers Offload 到 GPU 的层数
  • rope_scaling_type RoPE 缩放策略
  • rope_freq_base RoPE 基础频率
  • n_threads CPU 推理线程数
  • memory_type 计算时使用的数据类型
hparams = 模型结构，cparams = 运行时配置

Context & KV Cache

llama-context.cpp/h

  • struct llama_context 推理上下文，聚合所有状态
  • llama_context_init 初始化 KV cache, memory 等
  • llama_decode / llama_decode_batch 逐 token 前向传播
  • kv_self 引用 指向当前活跃的 KV cache

llama-kv-cache.cpp/h

  • llama_kv_cache_view KV cache 可视化/调试
  • kv_self 结构 per-layer K/V tensor 存储
  • kv_head 追踪 当前有效 token 位置
  • n_tokens, n_past batch 大小和历史长度
Context = 推理执行环境，包含 cache + state
KV Cache = 自回归生成的关键优化

Memory 系统 (多种实现)

llama-memory.cpp/h

标准 Memory 实现。维护 Layer 序列，每层包含 attention + FFN 状态。提供 cell 级别的细粒度管理和视图。

llama-kv-cells.h

llama-memory-hybrid.cpp/h

混合模式：部分层用 native 实现，部分用 ISWA。提供 n_native / n_iswa 参数配置混合比例。

hybrid 混合策略

llama-memory-hybrid-iswa.cpp/h

ISWA (Incredibly Sparse Window Attention) 实现的高效 sliding window memory。长序列支持优化。

sliding window

llama-memory-recurrent.cpp/h

Recurrent Memory：循环式状态管理，避免 KV cache 膨胀。适用于超长上下文场景 (Gemma 2 等)。

GRU-style recurrence
设计模式：抽象基类 + 多态实现，通过 llama_kv_cache 统一接口

Sampler & Grammar

llama-sampler.cpp/h

  • llama_sampler 采样器基类 + 工厂方法
  • 采样策略链 temp → top_k → top_p → min_p → tail_free → typical
  • llama_sampler_sample 执行采样选择 next token
  • llama_sampler_accept 接受采样的 token
  • llama_sampler_free 销毁采样器

llama-grammar.cpp/h

  • llama_grammar BNF 文法解析和状态机
  • llama_grammar_init 从 BNF 字符串解析文法
  • llama_grammar_sample 约束解码：mask 非法 token
  • llama_grammar_accept 更新状态机状态
  • JSON / 语法支持 常用约束格式
Sampler 支持链式组合，多种采样法叠加
Grammar 通过 token mask 实现约束解码

  • unicode_category Unicode 分类 (Ll, Lu, Nd...)
  • codepoint_to_utf8 码点 → UTF-8 字节
  • unicode-data.cpp Unicode 分类数据表 (生成)

Graph & 工具模块

llama-graph.cpp/h

计算图结构定义。llama.cpp 采用 ggml底层计算图，但在上层封装了 llm_graph_builder，用于描述 LLM 各层之间的依赖关系和执行顺序。

dependency graph

llama-impl.cpp/h

内部实现细节暴露。对内部实现的访问接口，供其他内部模块使用。通常包含不想公开但又需要跨模块共享的实现。

internal impl

llama.cpp (主入口)

所有 public API 的简单 wrapper。提供面向 C 的 API 接口层，将高级调用转发到各个模块。是 llama.h 的配套实现文件。

C API

llama-ext.h

Experimental / Extended API。实验性功能声明区，不稳定的 API。通常包含新特性、扩展功能的接口定义。

experimental

llama-mmap.cpp/h

跨平台内存映射实现。封装 POSIX mmap 和 Windows CreateFileMapping，提供统一的内存映射接口。

portable mmap

llama-adapter.cpp/h

模型适配器支持。用于 LoRA / Adapter 相关的权重复用和注入逻辑。

lora adapter
