模块概览

common/ 是 llama.cpp 的共享基础设施层，为所有示例程序和工具提供通用功能。

统一的模型加载和上下文管理

推理优化

Speculative decoding、KV cache

设计原则

  • DRY - 所有示例共享通用代码
  • 封装 - 隐藏底层细节，提供统一 API
  • 灵活 - 支持多种配置和扩展
  • 高效 - 线程安全，低开销
