GGUF File Format Structure

┌─────────────────────────────────────────────────────────┐
│  Header                                                  │
│  ┌──────────┬──────────┬──────────────┬──────────────┐ │
│  │  MAGIC   │  VERSION │ TENSOR_COUNT │    KV_COUNT  │ │
│  │  4 bytes │ 4 bytes  │   8 bytes    │    8 bytes   │ │
│  └──────────┴──────────┴──────────────┴──────────────┘ │
├─────────────────────────────────────────────────────────┤
│  KV Data (Key-Value Metadata)                           │
│  ┌─────────┬─────────┬─────────┬─────────┐             │

├─────────────────────────────────────────────────────────┤
│  Tensor Info                                             │
│  ┌────────────────────────────────────────────────────┐ │
│  │ Name | n_dims | dimensions | type | offset | ...   │ │
│  └────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│  Tensor Data (aligned to 32 bytes by default)           │
│  ┌────────────────────────────────────────────────────┐ │
│  │ [padding] tensor_0 tensor_1 ... tensor_n [padding] │ │
│  └────────────────────────────────────────────────────┘ │

GGUFReader: Reading GGUF Files

class GGUFReader:
    # Public API
    __init__(path, mode='r')
    get_field(key: str) → ReaderField | None
    get_tensor(idx: int) → ReaderTensor
    
    # Properties
    fields: OrderedDict[str, ReaderField]
    tensors: list[ReaderTensor]

class ReaderField(NamedTuple):
    offset: int
    name: str
    parts: list[np.ndarray]  # Raw data parts
    data: list[int]          # Indexes to actual data
    types: list[GGUFValueType]

class ReaderTensor(NamedTuple):
    name, tensor_type, shape
    n_elements, n_bytes
    data_offset, data: np.ndarray
    field: ReaderField

GGUFReader: Internal Flow

1 Memory-map the file using numpy memmap
2 Read header - Magic, Version, Tensor/KV counts
3 Build KV fields - Parse key-value metadata
4 Build tensor info - Name, dimensions, type, offset
5 Apply alignment - Pad to alignment boundary
6 Build tensors - Load actual tensor data 
# Endianness handling

GGUFWriter: Writing GGUF Files

class GGUFWriter:
    __init__(
        path, arch,
        use_temp_file=False,
        endianess=GGUFEndian.LITTLE,
        split_max_tensors=0,
        split_max_size=0
    )
    
    # Metadata API
    add_architecture()
    add_vocab_size(size)
    add_context_length(length)
    add_tensor_data_layout(layout)
    add_string/add_uint32/add_float32(key, val)
    add_array(key, val)
    
    # Tensor API
    add_tensor(name, tensor, raw_shape, raw_dtype)
    write_tensors_to_file(progress=False)
    
    # File operations
    close()

GGUFWriter: State Machine

NO_FILE

Initial state

→

EMPTY

File opened

→

HEADER

Magic + Version

→

KV_DATA

Metadata written

→

TI_DATA

Tensor info written

→

WEIGHTS

Complete

def write_to_file():
    writer.write_header_to_file()     # r: EMPTY → HEADER
    writer.write_kv_data_to_file()   # r: HEADER → KV_DATA
    writer.write_ti_data_to_file()    # r: KV_DATA → TI_DATA
    writer.write_tensors_to_file()    # r: TI_DATA → WEIGHTS
    writer.close()
