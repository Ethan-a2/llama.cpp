Framework

Custom Testing Framework (testing.h)

Core API

struct testing {
    void test(string name, F f);
    void bench(string name, F f, int iter);
    
    bool assert_true(bool cond);
    bool assert_equal(A expected, B actual);
    
    void set_filter(string regex);
    int  summary(); // 0 = success
};

Usage Pattern

int main() {
    testing t;
    t.test("name", [](testing & t) {
        t.assert_true(cond);
        t.assert_equal(exp, act);
    });
    return t.summary();
}

Testing Patterns

Pattern 1: Simple Assertions

#include <cassert>
int main() {
    assert(condition);
    assert(a == b);
}

Pattern 2: Custom Framework

t.test("case", [&](auto & t) {
    t.assert_true(cond);
    t.assert_equal(e, a);
});

Pattern 3: Vocab-Based

llama_model * m = llama_load_from_file(f);
auto tokens = tokenize(m, text);
assert(tokens == expected);

Pattern 4: Multi-Backend

double err = eval(backend_cpu, backend_cuda);
assert(err < threshold);

Key Insights

  • Custom lightweight framework - No external test dependencies, minimal overhead
  • Multi-backend verification - Ensures consistent results across CPU/CUDA/Metal/etc.

  • Tokenizer validation - BPE, SPM, and custom vocabularies

  • Fixture-based model loading - Automatic download and caching for tests
  • Thread safety verification - Concurrent inference correctness
