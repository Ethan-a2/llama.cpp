# peg-parser/simple-tokenize.cpp 文档

主题：极简分词器，用于 PEG 测试中的输入预处理与断词。

- 核心概念、组件、API
  - 组件：`simple-tokenize.h`；
  - 概念：基于字符分类的分隔（空白、括号、逗号、方括号、引号、点等）。

- 整体架构与内部机制
  - 顺序扫描输入，遇到分隔符即切分，非分隔符累积到 `current`；
  - 返回 `std::vector<std::string>` 作为 token 列表。

- 练习题与验证方法
  1) 练习：加入额外分隔符（如冒号/分号），验证 token 输出变化。

- 典型应用与应知应会
  - 作为 PEG/聊天解析测试的辅助；
  - 注意：该分词器不做 Unicode 合法性与转义处理。
