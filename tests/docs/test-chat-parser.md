# test-chat-parser.cpp 文档

主题：聊天解析与模板处理的单元测试，覆盖正则、部分匹配与日志。

- 核心概念、组件、API
  - 组件：`chat-parser.h`、`regex-partial.h`、`common.h`、`log.h`；
  - 概念：对话模板解析、消息角色/内容抽取、工具调用字段处理。

- 整体架构与内部机制
  - 定义输入样例→应用解析器→断言输出结构；
  - 处理边界：空行、缩进、特殊标记等。

- 详细分析与典型使用场景
  - 用于保障多模板来源（Jinja/Minja）的一致解析；
  - 服务端将用户输入与模板拼接后再解析校验。

- 设计优势与影响、关键要点
  - 优势：解析层的健壮性提升下游稳定性；
  - 关键：正则的部分匹配（partial）、多行文本安全处理。

- 练习题与验证方法
  1) 练习：添加一个包含多层嵌套工具调用的模板样例。
     - 验证：解析字段完整，未发生越界或错位。

- 后续建议与典型应用场景、应知应会
  - 建议：在 CI 中加入更多真实模板；
  - 应知应会：正则引擎行为差异、Unicode 处理。
  - 构建与运行：
    - 构建：`cmake -B build && cmake --build build --config Release -j $(nproc)`
    - 运行：`./build/bin/test-chat-parser`。
